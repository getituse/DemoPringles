# Pringles Wavy — 3D Interactive Showcase

An interactive 3D web experience built with React, Three.js, React Three Fiber, and GSAP.

## Features

- **Interactive 3D Can**: Real-time rendering with procedural materials, pointer drag-to-spin, and dynamic flavor textures.
- **Procedural Wavy Crisps**: Mathematically modeled 3D crisps with corrugation and hyperbolic-paraboloid saddle curves.
- **Flavor Selector Carousel**: Physics-driven semi-circular wheel featuring 7 flavors with smooth camera navigation.
- **Dynamic Theme Engine**: Color token interpolation and CSS variable transitions between flavors.
- **Smooth Motion & Scroll**: Integrated Lenis smooth scroll synchronized with GSAP ScrollTrigger ticker.

## Tech Stack

- **Framework**: React 19, TypeScript, Vite 7
- **3D Graphics**: Three.js, @react-three/fiber, @react-three/drei
- **Animation**: GSAP, ScrollTrigger, Lenis
- **Styling**: Tailwind CSS, Radix UI
